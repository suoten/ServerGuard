# ServerGuard 宝塔兼容性 — 前端测试用例

## 测试 10: 宝塔环境打开仪表盘

### 前置条件
- ServerGuard Agent 已安装并运行在宝塔面板服务器上
- ServerGuard Hub 已启动
- 前端服务可访问
- 宝塔面板环境已正确检测（`/www/server/panel` 存在且 `/etc/init.d/bt` 存在）

### 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 打开浏览器，访问 ServerGuard Web 控制台 | 页面正常加载 |
| 2 | 登录系统，进入仪表盘页面 | 仪表盘正常渲染 |
| 3 | 观察页面顶部 | 显示黄色（warning 类型）警告条 |
| 4 | 检查警告条标题 | 标题为"宝塔兼容模式已启用" |
| 5 | 检查警告条内容 | 包含"所有自动修复操作已降级为只告警"文字 |
| 6 | 检查警告条图标 | 左侧显示 warning 图标 |
| 7 | 检查警告条关闭按钮 | 无关闭按钮（`:closable="false"`），用户无法手动关闭 |
| 8 | 检查警告条 CSS class | 包含 `baota-banner` class |
| 9 | 刷新页面 | 警告条仍然显示（状态持久化） |
| 10 | 切换到其他页面再返回仪表盘 | 警告条仍然显示 |

### 验证条件
- `safety.baota_safe_mode` 为 `true` 时，`el-alert` 组件渲染
- 警告条 type 为 `warning`（黄色）
- 警告条不可关闭
- 警告条 CSS class 为 `baota-banner`

### 自动化验证（API 层）
```bash
# 验证 API 返回 baota_safe_mode = true
curl -s http://127.0.0.1:9090/api/safety | grep '"baota_safe_mode":true'
```

## 测试 11: 非宝塔环境打开仪表盘

### 前置条件
- ServerGuard Agent 已安装并运行在非宝塔面板服务器上
- ServerGuard Hub 已启动
- 前端服务可访问
- 服务器上不存在 `/www/server/panel` 目录或不存在 `/etc/init.d/bt` 文件

### 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 打开浏览器，访问 ServerGuard Web 控制台 | 页面正常加载 |
| 2 | 登录系统，进入仪表盘页面 | 仪表盘正常渲染 |
| 3 | 观察页面顶部 | **不显示**宝塔兼容模式警告条 |
| 4 | 检查 DOM 元素 | 不存在 `.baota-banner` 元素 |
| 5 | 检查 el-alert 组件 | 宝塔相关 `el-alert` 组件未渲染（`v-if="safety.baota_safe_mode"` 为 false） |
| 6 | 刷新页面 | 仍然不显示警告条 |

### 验证条件
- `safety.baota_safe_mode` 为 `false` 时，`el-alert` 组件不渲染
- 页面不包含 `baota-banner` CSS class

### 自动化验证（API 层）
```bash
# 验证 API 返回 baota_safe_mode = false
curl -s http://127.0.0.1:9090/api/safety | grep '"baota_safe_mode":false'
```
