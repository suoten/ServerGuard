# 宝塔SSL证书又过期了？你的站点变"不安全"了吗？

## 这可能是最"低级"的服务器事故

不是被黑客攻击，不是服务器宕机，不是数据库崩溃。

是你的SSL证书过期了。

用户打开你的网站，浏览器弹出一个红色警告：

**"您的连接不是私密连接"**

然后用户关掉了页面。

就这么简单。你流失了一个客户、一笔订单、一次信任。

而这一切的起因，仅仅是一个3个月就过期的免费证书，你忘了续期。

---

## 宝塔用户的痛

如果你用宝塔面板，你一定知道我在说什么。

宝塔提供免费的SSL证书，Let's Encrypt或者TrustAsia的。听起来很好，但有个致命问题：**有效期只有3个月**。

3个月！你记得住吗？

宝塔确实有"自动续期"功能。但用过的人都知道，它经常失败：

- DNS校验不通过（你换了DNS服务商，验证记录还在旧的上面）
- 站点配置改过（端口号变了、域名转发了）
- 宝塔版本升级后接口变了
- 80端口被占用了（ACME验证需要80端口）
- 你根本不知道它失败了（宝塔续期失败不会给你发告警）

结果就是：你以为证书自动续了，其实没续上。用户告诉你"你网站打不开了"，你一查才发现证书过期了。

然后你登录宝塔，站点设置，SSL，重新申请，等校验，部署……每次5到10分钟。

如果是一大早发现的还好。如果是凌晨发现的呢？如果是周末呢？如果你有5个站点、10个站点呢？

---

## 我被坑了之后做了什么

去年某天，我的一个客户站点证书过期了。

用户投诉过来的时候，我才知道。打开网站一看，大红叉，"不安全"。客户以为网站被黑了。

我赶紧登录宝塔重新申请证书，折腾了10分钟恢复。但已经流失了半天的流量。

我当时就想：**有没有什么东西能提前告诉我证书快过期了，然后自动帮我续？**

我找了找，发现一个都没有。

- 宝塔：只有续期功能，失败不会告警
- Zabbix：可以监控证书过期，但不会自动续期
- 阿里云监控：只管云上的证书，不管你在宝塔上申请的
- certbot：能自动续，但不会告警，也不会通过宝塔API续

于是我自己写了一个。就是ServerGuard的证书守护模块。

---

## 它怎么帮你守证书

装上去之后，它会自动干三件事：

### 第一件：扫描你所有的证书

它扫描你服务器上所有443、8443端口的HTTPS站点，解析Nginx/Apache/宝塔的配置文件，把所有证书信息提出来——域名、颁发者、有效期、密钥长度。

不用你告诉它有什么站点，它自己发现。

### 第二件：到期分级告警

| 距离到期 | 告警级别 | 发到哪 |
|---------|---------|--------|
| 30天 | 提醒 | 邮件 + 面板 |
| 14天 | 警告 | 微信 + 钉钉 |
| 7天 | 紧急 | 全渠道 |
| 3天 | 致命 | 全渠道 + 电话 |
| 1天 | 临界 | 全渠道 + 电话 |

你永远不会再"忘记续证书"了。

### 第三件：自动续期

这是最核心的。证书到期前14天，它自动触发续期：

**如果你用的是宝塔**，它直接调宝塔API帮你续期，不消耗ACME配额。续完自动部署，自动reload Nginx。

**如果宝塔API失败**，它切换到ACME协议续期，多CA降级链：Let's Encrypt → ZeroSSL → TrustAsia，挨个试。

**如果全部失败**，它立即全渠道告警，附上手动续期教程链接，你自己几分钟就能搞定。

续期后还会验证：新证书生效了吗？HTTPS探测正常吗？不正常就回滚到旧证书。
